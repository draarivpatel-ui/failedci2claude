01 · THE PROBLEM

CI fails after the agent stopped looking.

A pull request goes red minutes after the turn ends. Nobody tells the session, so you copy the error across by hand. This is the same push, with the hook on.

    03 · BY THE NUMBERS
    
  
    Small on purpose.

    0
    GH CALLS PER RUN
    One gh pr list for all your open PRs, not one per branch.
    
    
    0
    TESTS
    Real script, real temp git repo, a stub gh. No network.
    
    
    9
    REPEAT REPORTS
    A failure is reported once per commit, so the hook cannot loop.
    
    
    0
    SECOND BUDGET
    The hook timeout. A normal run takes about one second.
    
  
    

    


    
  
    04 · HOOK VS AUTO-FIX
    
  
    Two tools. Different moments.
    
  
    The hook runs inside your session. The desktop app's Auto-fix watches from outside. Use both.
